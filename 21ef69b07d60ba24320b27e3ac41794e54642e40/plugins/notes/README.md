# Notes 便签

A note on the desktop. Click the text to write; Esc, Ctrl+Enter or a click elsewhere saves it.
A line that starts with `[ ]` is a to-do: PecoFence draws a check box in front of it, and a click on
the box ticks it without opening the editor. Enter on a to-do line starts the next one.

PecoFence edits and keeps the text itself, with the fence in its configuration: backups, export,
import and layout snapshots carry it, as they carry its own note fences. The plugin only tells
PecoFence where the note goes, so a note keeps working the same when the plugin is updated.

Sends nothing over the network and asks for no permissions.

---

桌面上的便签。单击文字开始写，按 Esc、Ctrl+Enter 或点别处保存。以 `[ ]` 开头的行是待办，前面显示一个方框，
不用打开编辑也能直接勾选；在待办那一行按 Enter，下一行自动带一个方框。

文字由 PecoFence 编辑和保存，跟着栅栏存在配置里，所以备份、导出、导入和布局快照都会带上它。
不联网，不需要任何权限。
