# Launcher 启动器

Put the programs, files and folders you use often into this fence: drop them on it (at most 20 at a
time), or right-click it and choose *Add a program…*, *Add a file…* or *Add a folder…*. One click opens an item, as a
fence icon opens; a shortcut opens with its own arguments. In the plugin's details, Settings › 小工具,
you can give the command *Show the launcher* a shortcut: it brings this fence up over all windows.
Remove items there too.

The plugin knows each item by its name and picture only: PecoFence keeps where it is and opens it.
It sends nothing over the network.

把常用的程序、文件和文件夹放进这个栅栏：拖到它上面（一次最多 20 个），或者右键栅栏选「添加程序…」「添加文件…」「添加文件夹…」。
点一下就打开，和点栅栏里的图标一样；快捷方式带着它自己的参数打开。在设置 › 小工具的插件详情里，可以给「显示启动器」
设一个快捷键，按下时这个栅栏浮到所有窗口上面；条目也可以在那里移除。插件只知道条目的名字和图片，路径由 PecoFence
保存，也由 PecoFence 打开。不联网。
