# To-do 待办

A to-do list in a fence. Click the top line, type a task and press Enter. Click a task to tick it;
tasks that are done turn grey and go under the others. Right-click a task to delete it; the fence
menu deletes every task that is done. In the fence menu, Plugin settings, you can hide the tasks
that are done.

Each fence keeps its own list, in a data file of the plugin named after the fence. It stays on this
computer: the plugin sends nothing over the network and asks for no permissions. At most 200 tasks
a fence.

栅栏里的待办清单。点最上面一行，输入一件事，按 Enter 添加；点一件事就打勾，做完的变灰、排到后面。
右键一件事可以删除它，栅栏菜单里可以删除所有已完成的事项；在「插件设置」里可以隐藏已完成的事项。
每个栅栏有自己的清单，保存在这台电脑上。不联网，不需要任何权限。每个栅栏最多 200 项。
