# Daily log 每日记录

Write what you are doing in the box and press Ctrl+Enter: the line goes, with the time, into
today's Markdown file in a folder you choose, for example `Documents\Log\2026-11\2026-11-16.md`.
The fence shows today's lines.

- Click the fence, or right-click it and choose *Choose a folder…*, to pick the folder. PecoFence
  asks you; the plugin can write only there, and PecoFence refuses system and program folders,
  AppData, the root of a drive and your user folder itself.
- *Move today's log to the Recycle Bin* in the same menu moves today's file to the Recycle Bin.
- Permission: `folders: "readwrite"` (reads and writes the folder you pick). It writes Markdown
  files and makes one folder a month, nothing else, and sends nothing over the network.

---

在框里写下现在在做的事，按 Ctrl+Enter：这一句带着时间记进你选的文件夹里当天的 Markdown 文件，例如
`文档\Log\2026-11\2026-11-16.md`。栅栏里显示今天记下的内容。点栅栏，或者右键栅栏选「选择文件夹…」来选文件夹：由
PecoFence 来问你，插件只能写在这个文件夹里，系统文件夹、程序文件夹、AppData、磁盘的根目录和你的用户文件夹本身都不能选。
同一个菜单里的「把今天的记录移到回收站」把今天的文件移到回收站。权限：`folders: "readwrite"`（读写你选的文件夹）。它只写
Markdown 文件，每个月建一个文件夹，不联网。
